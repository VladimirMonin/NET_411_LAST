## Почему venv и pip не всегда удобны?

### Ограничения классического подхода

- venv занимается только виртуальным окружением
- pip занимается только пакетами
- requirements.txt приходится поддерживать отдельно
- Необходимо вручную создавать и активировать окружение
- Необходимо отдельно следить за зависимостями проекта
- Для обычной работы используется сразу несколько отдельных механизмов

### Почему venv и pip всё равно важно знать

- Они доступны практически в любой современной установке Python
- Они используются в огромном количестве существующих проектов
- Они помогают понять базовую механику виртуальных окружений
- Они остаются хорошим запасным вариантом
- Современные инструменты во многом автоматизируют именно те действия, которые раньше выполнялись через venv и pip
